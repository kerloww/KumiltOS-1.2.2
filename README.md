# KumiltOS-1.2.2
🌌 Kumilt OS v1.2.2
Kumilt OS — это 32-битная операционная система, написанная с нуля. Ядро на C и Assembly, мак-подобный интерфейс и браузер на Rust.

• Что внутри
Ядро: x86, прерывания, VESA-графика, драйверы мыши/клавиатуры, своя файловая система.

GUI: Оконный менеджер, Док с анимацией, меню-бар, перетаскивание окон.
Приложения по умолчанию: Explorer, Терминал, Калькулятор, Блокнот, KumiltWEB, Инфо., Диспетчер задач, Настройки.

🛠️ Стек
C • Assembly (NASM) • Rust (в разработке)
